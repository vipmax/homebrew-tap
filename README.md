# Homebrew Tap for AnyDiff

Official [Homebrew](https://brew.sh/) tap for [AnyDiff](https://github.com/vipmax/anydiff) — High-performance native macOS MultiBuffer Diff editor with embedded AI agent.

## Installation

```bash
brew install --cask vipmax/tap/anydiff
```

Or add the tap first:

```bash
brew tap vipmax/tap
brew install --cask anydiff
```

## CLI Usage

Once installed, use the `anydiff` command anywhere:

```bash
anydiff .                      # Open diff in current git repository
anydiff ~/dev/my-project       # Open specific project
```

## Updating

```bash
brew upgrade --cask anydiff
```
